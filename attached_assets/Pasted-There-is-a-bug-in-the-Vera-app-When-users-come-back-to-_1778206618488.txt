There is a bug in the Vera app. When users come back to the app, their old chat conversations disappear. Please fix this by doing the following:

1. FIND wherever the chat messages are stored in state, it will look something like this:
   const [messages, setMessages] = useState([...])

2. REPLACE the useState for messages with this persistent version:

const [messages, setMessages] = useState(() => {
  try {
    const saved = localStorage.getItem("vera_chat_history");
    if (!saved) return [{ role: "assistant", content: "Hey. I'm Adit. I'm here. What's on your mind?" }];
    const parsed = JSON.parse(saved);
    return Array.isArray(parsed) && parsed.length > 0 
      ? parsed 
      : [{ role: "assistant", content: "Hey. I'm Adit. I'm here. What's on your mind?" }];
  } catch {
    return [{ role: "assistant", content: "Hey. I'm Adit. I'm here. What's on your mind?" }];
  }
});

3. ADD this useEffect right after the messages useState to save every new message automatically:

useEffect(() => {
  try {
    localStorage.setItem("vera_chat_history", JSON.stringify(messages));
  } catch (e) {
    console.error("Failed to save chat history:", e);
  }
}, [messages]);

4. ADD a "New Chat" button somewhere in the header or sidebar that clears the current conversation and starts fresh. The button should do this when clicked:

const handleNewChat = () => {
  if (window.confirm("Start a new conversation? Your current chat will be saved separately.")) {
    const archived = JSON.parse(localStorage.getItem("vera_past_chats") || "[]");
    archived.unshift({ id: Date.now(), messages, savedAt: new Date().toISOString() });
    localStorage.setItem("vera_past_chats", JSON.stringify(archived.slice(0, 20)));
    const fresh = [{ role: "assistant", content: "Hey. I'm here. What's on your mind?" }];
    setMessages(fresh);
  }
};

5. ADD a past chats sidebar or section that loads and displays previous conversations. Each past chat should show:
   - The date it was saved
   - The first user message as a preview
   - A button to view the full conversation

6. MAKE SURE no other part of the code is resetting messages to an empty array or the default greeting on page load or component re-render.
